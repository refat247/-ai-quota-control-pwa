# Support

Start with the [project README](README.md) for the current app address, browser checks, and release status.

For reproducible app bugs, use [GitHub Issues](https://github.com/refat247/-ai-quota-control-pwa/issues). Include the app version, browser and OS, steps to reproduce, and expected and actual behavior. Use synthetic quota data for examples.

Keep subscription exports, billing details, account identifiers, tokens, and screenshots containing private data out of public issues. For a suspected security issue, use a private reporting channel only if the repository's Security tab offers one. Avoid posting exploit details or private evidence in public Issues.
