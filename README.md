# AI Quota Control PWA

This public repository is reserved for a **privacy-safe, mobile-first offline-ready AI quota dashboard**.

**Status:** Initial repository setup only. The application release and GitHub Pages deployment are not yet approved through a reviewed pull request.

Personal account emails, quota percentages, subscription records and private JSON backups must **never** be committed here. The public application starts with zero personal records; a user imports their own JSON in their browser.

Project releases follow SemVer, a changelog, a focused pull request and owner-controlled merge. This initial README does not represent a deployed version.

Canonical KOS workstream: `CROSS-SUBSCRIPTION-AI-ROUTING`.
